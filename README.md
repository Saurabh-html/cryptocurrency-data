
# Live Cryptocurrency Tracker with Excel Auto-Update  

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Excel](https://img.shields.io/badge/Excel-Live%20Data-green)

Fetches live cryptocurrency data, analyzes trends, and updates an Excel sheet automatically. Perfect for real-time market tracking!

## Features  
- 🚀 **Live Data Fetching**: Top 50 cryptos by market cap (price, volume, % change).  
- 📊 **Automated Excel Updates**: Refreshes every 5 minutes.  
- 📈 **Analysis**: Top 5 cryptos, average price, highest/lowest volatility.  
- 🛠️ **Robust Error Handling**: Retries, logging, and rate limiting.
